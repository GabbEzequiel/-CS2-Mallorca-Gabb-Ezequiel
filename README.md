# Travel Fare Calculator

## Description 
This program calculates the cost of the total fare based on the rate, distance, and number of passengers. 

## Version 1 – Original code without input validation
- Input: Accepts passenger's name, distance (km), and number of passengers.
- Process: Calculates total fair, and displays it rounded to 2 decimal places.
- Output: Name of passenger and total fair.
- Does not include input validation.

 ## Version 2 - Updated code with input validation
- Input: Accepts passenger's name, distance (km), and number of passengers. 
- Process: Calculates total fair, and displays it rounded to 2 decimal places.
- Output: Name of passenger and total fair.
- Includes input validation
- 
## Input Validation Rules:
- Passenger Name: Rejects empty inputs or empty spaces.
- Distance (km): Rejects text, symbols, and numbers less than or equal to 0 (allows decimals).
- Number of Passengers: Rejects decimals, text, symbols, and numbers less than or equal to 0 (strictly positive whole numbers).
