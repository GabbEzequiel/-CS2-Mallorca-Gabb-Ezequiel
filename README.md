# Travel Fare Calculator

## Description 
This program calculates the cost of the total fare based on the rate, distance, and number of passengers. 

## Version 1 – Original code withoutinput validation
- Input: Accepts passenger's name, distance (km), and number of pasengers.
- Process: Calculates total fair, and displays it rounded to 2 decimal places.
- Output: Name of passenger and total fair.
- Does not include input validation.
